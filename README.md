# Bid or Bury

Most app ideas are trash. A few are underpriced.
Vote in public. Bid if you see the value they don’t.

Public junkyard for **ideas**, **GitHub repos**, and **live apps**.

- Vote good / trash with no account
- Watch a listing with email after you vote
- Offer only on repos and live apps
- Ideas are bait. Artifacts are inventory.

Live repo: https://github.com/chkae88-pixel/bid-or-bury

## Open it

Open `index.html` in a browser, or enable GitHub Pages:

1. Repo → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Save. Site will be at
   `https://chkae88-pixel.github.io/bid-or-bury/`

## What this MVP stores

Everything lives in **your browser** (`localStorage`).
There is no server yet. Offers and emails do not leave the device
until you export them from Desk.

Desk: `#/operator` — export JSON of votes, watchers, offers, submissions.

## 72-hour scoreboard

1. Serious offers (email + $ + listing)
2. Watcher emails
3. External submissions
4. Votes (vanity)

House seeds do not count as demand.
